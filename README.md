# FNF-Mods-de-PC-A-Android
Un día por accidente descargué un mod de pc para mi teléfono, así que programé esto para poder jugarlo.

# Que hace este programa?
Este programa convierte los archivos json de las canciones, los personajes y dialogos a un formato que soporta el FNF de Android. Por ahora soporta dos verciones de archivos de los mods de PC

# Como funciona?
Este programa funciona de una manera muy simple, solo nececita que ingreses la direción de los archivos de la cancion y sus eventos si el mod no contiene eventos puedes simplemente dejar esa opción en blanco. El programa te devolvera una carpeta con el nombre de la cancion que contiene los archivos chart y metadata.

# Como instalar el mod convertido?
Para instalar este mod simplemente tienes que mover los archivos a la direccion siguiente en tu telefono : Android/data/me.funkin.fnf/files/mods.
